PROJECT OVERVIEW
----------------
BimaVani = a production-grade, HINGLISH VOICE-FIRST Roadside Assistance
(RSA) + IRDAI Claim Desk "Helpline" (1-800-BIMA-VANI) for Indian drivers
— a hackathon project (deadline: November 10). Root:
  /Users/kunal/Desktop/voice_agents/bhimVANI

It proves ONE thesis end-to-end:
  "A voice agent that survives loud Indian highway noise, student-tier
   API rate limits, and mid-sentence barge-in corrections — while
   safely dispatching real-world RSA workflows and auto-drafting
   IRDAI-compliant claim numbers."

Domain: 24x7 RSA helpline for cars/2-wheelers on NH-44 (National
Highway), city roads, and rural link roads — injury triage (112/1033),
NCB-protecting minor breakdowns, flatbed tow dispatch, and an
auto-filled FNOL claim draft with spoken read-back confirmation.

HYBRID STREAMING-TURN VOICE ARCHITECTURE (8-STAGE PIPELINE)
----------------------------------------------------------
Turn-taking state machine + barge-in controller (stop & flush ALL <50ms)
gates every stage:

  [1. Microphone]        16kHz Mono 16-bit Linear PCM WAV recorded in
                         browser (+ Web Audio Indian Highway Noise Mixer)
  [2. Gnani Prisma]      POST https://api.vachana.ai/stt/v3 Hinglish ASR
                         (prisma-v2.5 default; prisma-v3.0 supported)
  [3. Endpointing]       Push-to-Talk default + optional 600ms silence
                         Auto-VAD (20ms frame energy gate)
  [4. Brain]             Deterministic Hinglish entity extractor +
                         tool-calling state machine (Injury / RSA /
                         Claim tools) + short/long-term memory
                         (optional OpenAI-compatible LLM adapter for
                         gnani/gnani-evon-v3.3-30B-A3B / Groq / Gemini)
  [5. 2-Clause Buffer]   Every reply split into <=2 spoken clauses:
                         Clause 1 fast empathy/triage hook (sent to TTS
                         first, sub-400ms time-to-first-audio),
                         Clause 2 actionable RSA + claim read-back
  [6. Gnani Timbre]      POST https://api.vachana.ai/api/v1/tts/inference
                         (timbre-v2.5 default; NEVER timbre-v2.0 — retired)
                         24kHz PCM WAV + 44-byte RIFF wrapper + MD5 cache
  [7. Jitter Buffer]     Browser Web Audio Queue: 120ms prebuffer of
                         Clause 1, Clause 2 scheduled gaplessly next
  [8. Speaker]           Agent voice out; next turn returns to stage 1

GNANI.AI ECOSYSTEM CONTRACTS
----------------------------
- Console/keys: https://app.gnani.ai/voice   Docs: https://docs.gnani.ai
- Env var: GNANI_API_KEY (sent as HTTP header "X-API-Key-ID: <key>")
- Student keys: STRICT 1-request-at-a-time -> guardrails:
    * backend/gnani_client.py wraps ALL live calls in asyncio.Semaphore(1)
    * auto-retry on HTTP 429 / 5xx with exponential backoff
    * MD5 disk cache in backend/cache/tts/ so re-runs cost 0 credits
- STT (Prisma): POST https://api.vachana.ai/stt/v3
    multipart: audio_file=("call_turn.wav", bytes, "audio/wav")
    form: model, language_code, format, preferred_language, keyterms
    GNANI_STT_MODEL=prisma-v2.5 (default) | prisma-v3.0
    language_code: hi-IN (default) | indic-auto | en-IN | mr-IN | ta-IN | te-IN
    format: codemix | transcribe; preferred_language: hi-IN
    keyterms: Splendor,Swift,Activa,Bolero,NH-44,Karnal,radiator,bumper,
              headlight,axle,puncture,cashless,policy
    read: transcript, request_id, exact latency ms
- TTS (Timbre): POST https://api.vachana.ai/api/v1/tts/inference
    JSON: {"text", "voice":"Nalini", "model":"timbre-v2.5",
           "language":"hi-IN", "speed":1.0,
           "audio_config":{"sample_rate":24000,"encoding":"linear_pcm",
                           "container":"wav"}}
    NEVER model "timbre-v2.0" (retired).
    If bytes don't start with b"RIFF" -> wrap raw PCM in a 44-byte
    RIFF/WAVE header (16-bit mono 24kHz) before returning.
- Optional SDK: `gnani-vachana` package (gnani.stt.GnaniSTTClient,
  gnani.tts.GnaniTTSClient) — REST httpx path is primary/default.
- Credit-Shield Fallback Mode: with NO key configured, the app still
  runs 100% (deterministic transcript pass-through + locally generated
  spoken-tone WAV) so the live demo never crashes.
- Brain LLM adapter (optional, OpenAI-compatible chat-completions):
    model id "gnani/gnani-evon-v3.3-30B-A3B" or Groq/Gemini key via env.
    DEFAULT = deterministic extractor/state machine; ZERO LLM required.

DOMAIN RULES (backend/rsa_and_claim_rules.py)
---------------------------------------------
- Tool 1 triage_injury_and_safety: keywords chot/khoon/injured/behosh/
  fracture/ambulance/hospital -> halt claims, 112 + 1033 + human handoff.
- Tool 2 dispatch_smart_rsa(road_type, parts, is_drivable, policy):
    Workflow A minor breakdown (puncture/battery/keys/fuel): on-spot bike
      mechanic ETA 22 min + PROTECT 20% NCB (tell driver NOT to claim).
    Workflow B non-drivable (radiator/coolant/axle/smoke/EV stuck):
      "Do NOT start engine", 1033 cones on NH, free flatbed tow <=50km to
      cashless garage; rural ETA>2h -> IRDAI ₹1,500 local towing
      reimbursement authorization.
    Workflow C drivable minor (bumper dent/headlight/mirror): 4 photos
      with plate visible + drive to cashless garage.
- Tool 3 calculate_irdai_claim_draft(policy_number, parts): compulsory
  deductible ₹100 (2W) / ₹1,000 (4W), depreciation, estimated ₹ range,
  labeled "Estimated Range Subject to Surveyor Inspection — Not Final".
- Policies: 7820 Maruti Swift Zero-Dep, 4491 Honda Activa Zero-Dep,
  1055 Hero Splendor+ Zero-Dep, 9932 Mahindra Bolero Standard,
  3310 Tata Nexon EV Zero-Dep (all synthetic).
- Multi-turn loop: Turn 1 incident -> ticket+FNOL+spoken read-back;
  Turn 2/barge-in "haan confirm" OR field fix ("policy 1055 hai!") ->
  DISPATCHED & INTIMATED ✅.
- Spoken Hindi numeral parser: maps "saat hazaar aath sau bees" /
  "seven eight two zero" / "7820" -> int; must handle 7820 vs 4491
  barge-in corrections.
